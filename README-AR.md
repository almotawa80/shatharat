# حكم وأمثال

موقع ثابت على GitHub Pages لحكم وأمثال د. عبدالعزيز فيصل المطوع. الحكم مضمّنة في `seed.js` فيعمل الموقع للقراءة والمشاركة مباشرة.

## تفعيل لوحة الإضافة (Supabase)
1. افتح مشروع Supabase الخاص بديواني، ثم SQL Editor ← New query، والصق `supabase-setup.sql` واضغط Run.
2. في استعلام جديد الصق `supabase-data.sql` واضغط Run (يُدخل الحكم كلها).
3. شغّل السطر الأخير في `supabase-setup.sql` بعد وضع بريدك لتصبح المالك.
4. ضع رابط المشروع والمفتاح العام anon في `config.js` (موجودان في Project Settings ← API، وهما نفس قيم ديواني).
